# Deffbites
The following is an interactive and modern food delivery website that includes a home page, a categorized menu, about and a add to cart facility with schedule for later and specific instructions features. It is built using HTML, CSS, and basic JavaScript.


Key Features:
Attractive and interactive Home and Menu pages
Categorized food items including pizza, burgers, biryani, pasta, chicken, and more
Separate restaurant menus with food items, prices, reviews, and restaurant information
Student deals and combo offers
Interactive cart with quantity controls and item removal
Specifications section for adding special food requirements
Schedule for Later option for selecting a preferred delivery time
Promo code application and discount calculation
Dynamic bill with delivery, platform, and other charges


Technologies Used:
HTML5 – Structure and content
CSS3 – Styling and responsive layout
JavaScript – Interactive functionality and cart management


Project Flow:

Browse → Select Food → Add to Cart → Customize → Schedule → Apply Promo → Checkout
